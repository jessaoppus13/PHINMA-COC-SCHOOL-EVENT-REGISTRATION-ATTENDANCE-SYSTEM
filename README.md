PHINMA COC School Event Registration & Attendance System

Project Overview
The PHINMA COC School Event Registration & Attendance System is a desktop-based application developed to manage school event registration and attendance monitoring at PHINMA Cagayan de Oro College – Puerto Campus.

Technologies Used
- Java
- Java Swing
- NetBeans IDE
- MySQL
- XAMPP
- JDBC
- phpMyAdmin

System Features

Student Module
- Student Registration and Login
- View Available School Events
- Event Registration
- View Registration Status
- View Attendance Records

Staff Module
- Staff Login
- Dashboard and Event Statistics
- Create and Manage Events
- View Student Registrations
- Monitor Student Attendance
- Generate and View Event Records

Database
Database Name: `event_registration`

The SQL database backup is included in this repository as `event_registration.sql`.

Development Methodology
Agile Software Development Life Cycle (Agile SDLC) with Scrum.

Installation and Setup
1. Install NetBeans IDE and XAMPP.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin.
4. Create or import the `event_registration` database using the included SQL file.
5. Open the project in NetBeans IDE.
6. Configure the database connection in `DBConnection.java`.
7. Add the required external libraries.
8. Run the project using NetBeans.
